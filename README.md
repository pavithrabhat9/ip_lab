# IP Lab

Image Processing Lab exercises implemented in Python using Jupyter Notebook.

## About

This repository contains lab exercises exploring core image processing concepts and techniques, worked through in a Jupyter Notebook.

## Contents

| File | Description |
|------|--------------|
| `Exercise (1).ipynb` | Lab exercise notebook covering image processing operations |

## Tech Stack

- Python 3
- Jupyter Notebook
- NumPy
- OpenCV / Pillow
- Matplotlib

## Getting Started

### Prerequisites

```bash
pip install jupyter numpy opencv-python pillow matplotlib
```

### Run

```bash
git clone https://github.com/pavithrabhat9/ip_lab.git
cd ip_lab
jupyter notebook
```

Open `Exercise (1).ipynb` and run the cells in order.
